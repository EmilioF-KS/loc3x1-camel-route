# Contributing Guide

Thank you for contributing to the LOC3X1 agentic pipeline project.

## Repository Structure
- `agent/` — Python agent (LangGraph pipeline, deterministic converters)
- `backend/` — FastAPI backend exposing API endpoints and SSE
- `generated/` — Spring Boot + Camel YAML projects generated by the pipeline
- `examples/` — Example input trees and payloads
- `doc/` — Documentation and backlog (jira-tickets.md)
- `ci/` — CI-related docs and helper scripts
- `.github/` — PR templates and workflows

## Branching Strategy
- Use trunk-based development with feature branches: `feature/<ticket-id>-<short-name>`
- PRs target `main` and must pass CI gates before merge
- Keep PRs focused; one logical change per PR

## Coding Standards
- Python: PEP8, type hints, pytest for tests
- Java: Follow project defaults (Java 17), unit tests with JUnit
- YAML: Camel YAML DSL must validate via schema; keep routes modular

## Commit Messages
- Use imperative mood: `Add`, `Fix`, `Refactor`
- Reference ticket IDs when applicable (e.g., `AGENT-010`)

## PR Checklist
- [ ] Tests added/updated for changed code
- [ ] Lint passes (Python), code compiles (Java)
- [ ] Schema validations pass (XML/XSD)
- [ ] Camel YAML DSL validates and routes build
- [ ] Documentation updated (if applicable)

## CI Gates (Overview)
- Python setup and dependency install (`requirements.txt`)
- Syntax check / basic lint
- Run tests (pytest / JUnit) when present
- Future: schema validation, Camel YAML DSL validation, and build gates

## How to Run Locally
- Python venv: `python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`
- Backend: `python api.py` (starts FastAPI on port 8000)

## Reporting Issues
- Open an issue with a clear description, repro steps, and expected behavior
