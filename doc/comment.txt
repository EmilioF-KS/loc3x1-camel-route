- **Docs:** `doc/Loc-Camlel-Route.tex` (PDF-ready), 9-agent pipeline defined

- **Pending:** Maven scaffold, CXF/JAXB generation, Spring Boot service, Camel routes, MapStruct mappings, tests

**CONTRACT DISCOVERY:**

- Group into bundles, produce unified inventory
- Contracts are authoritative for generation/wiring/orchestration

**WORKFLOW:**
1. **Preflight:** Activate `venv`, run `scripts/preflight.sh` → `doc/tooling-report.md`
2. **Tickets:** Process `doc/jira-tickets.txt` starting LOC-001 (Contract Inventory)
3. **Discovery:** Build inventory (namespaces, bindings, operations, fault schemas)
4. **Generation:** CXF/JAXB from WSDL/XSD (document/literal SOAP)
5. **Scaffold:** Maven parent+modules (contracts, services, clients, mappings, orchestration, tests)
6. **Services/Clients:** Spring Boot+CXF inbound, CXF outbound clients
7. **Orchestration:** Camel routes mirror BPEL sequencing/error paths
8. **Mappings:** MapStruct replaces BPEL `assign` activities
9. **Testing:** Real endpoints, harvest logs, auto-fix failures
10. **Documentation:** Update LaTeX, ticket statuses, diagrams

**PRINCIPLES:**
- Contract-first: WSDL/XSD/BPEL authoritative
- Production-ready: error handling, logging, configuration
- Real endpoints only, no mocks
- Deterministic MapStruct mappings
- British English, no secrets in repo
